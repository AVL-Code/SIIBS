# General & Cross-Cutting Skills (`SIIBS/.agents/skills/`)

Place general, cross-cutting, testing, security, SDD, or operational skills here (each in its own `<skill-name>/SKILL.md` folder).

## How Agents Discover These Skills
- Registered automatically via [`.agents/skills.json`](../skills.json).
- Used primarily by the **Orchestrator**, **Spec & Architecture Agent**, and **QA & Security Agent**, and available as shared reference to **Backend** and **Frontend** agents when needed.
